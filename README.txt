작업완료 확인서 작성기 - Android PWA 검토용

이 파일은 APK가 아니라, 앱처럼 설치 가능한 웹앱(PWA) 패키지입니다.

사용 방법:
1. 이 ZIP 파일을 압축 해제합니다.
2. index.html을 PC에서 열어 양식을 검토합니다.
3. 안드로이드에서 앱처럼 설치하려면 이 폴더를 HTTPS 웹주소에 올려야 합니다.
   예: 회사 서버, GitHub Pages, Netlify, Firebase Hosting 등
4. 안드로이드 Chrome에서 해당 주소 접속 후 메뉴에서 '홈 화면에 추가' 또는 '앱 설치'를 누릅니다.

중요:
- 로고/서명/입력값은 사용 중인 브라우저의 로컬 저장소에 저장됩니다.
- 다른 휴대폰과 자동 동기화되지는 않습니다.
- 실제 APK 설치파일이 필요하면 Android Studio/WebView 방식으로 한 번 더 패키징해야 합니다.
