작업완료 확인서 작성기 blank v3

반영 내용:
1. 배포 시 기본 입력값을 모두 공란으로 변경했습니다.
2. 확인란도 기본 3행만 있고 내용은 모두 공란입니다.
3. 회사 로고는 선택하면 브라우저 localStorage에 자동 저장됩니다.
4. 로고 지우기 버튼을 추가했습니다.
5. 서명 이미지가 없으면 출력 확인칸은 완전 공백으로 표시됩니다.
6. A4 한 페이지 PDF 출력에 맞도록 여백, 글자 크기, 행 높이를 조정했습니다.
7. 캐시명을 v3로 변경하여 GitHub Pages 업데이트 반영성을 높였습니다.

GitHub Pages 업데이트 방법:
1. 이 ZIP을 압축 해제합니다.
2. GitHub 저장소 Code 화면으로 갑니다.
3. Add file > Upload files를 누릅니다.
4. 압축 해제한 안쪽 파일(index.html, manifest.json, service-worker.js, icons 폴더)을 업로드합니다.
5. Commit changes를 누릅니다.
6. Actions 또는 Settings > Pages에서 배포 완료를 기다립니다.

주의:
- 이미 휴대폰에 앱처럼 설치해둔 경우 예전 캐시가 잠깐 남을 수 있습니다.
- 새 버전이 안 보이면 브라우저에서 새로고침하거나, 설치한 홈화면 아이콘을 삭제 후 다시 추가해보세요.
- 한 페이지 출력은 기본 공란 양식 및 일반 입력량 기준입니다. 내용이 매우 길면 표가 작아지거나 추가 조정이 필요할 수 있습니다.
